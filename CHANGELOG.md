# Changelog

## [0.1.0] - 2026-07-01

### Adicionado
- Arquitetura agnóstica multi-conector
- Suporte a MySQL/MariaDB e PostgreSQL
- Adaptadores MySQLAdapter e PostgreSQLAdapter
- Gestão de usuários DB com LOCK/UNLOCK
- Feature flag para Console SQL
- Detecção de HTTPS na Saúde do Sistema
- Separação física glpi_local/glpi_reports
- ETL incremental com janela de segurança
- Dashboard com widgets KPI, GAUGE, BARRA, PIZZA, TABELA, COMPARATIVO
- Export PDF e Excel
- Autenticação local e LDAP com fallback
- Rate limiting e proteção CSRF
- Permissões granulares 6 níveis
