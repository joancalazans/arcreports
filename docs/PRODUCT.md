# ArcReports

**ArcReports** é uma plataforma agnóstica de replicação e análise de dados para BI e relatórios operacionais.

## Conectores suportados
- GLPI (MySQL/MariaDB)
- Zabbix (PostgreSQL + TimescaleDB)
- Redmine (MySQL/MariaDB ou PostgreSQL)
- Qualquer banco MySQL ou PostgreSQL
